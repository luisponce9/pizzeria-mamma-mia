# 🍕 Pizzería Mamma Mia! - Proyecto Final

Aplicación web desarrollada con React y Vite para la gestión y visualización del catálogo de una pizzería. Este proyecto se construye de forma iterativa, sumando funcionalidades en cada hito de desarrollo del curso.

## 📌 Progreso del Proyecto

- [x] **Hito 1:** Maquetación y Componentes Estáticos.

## 🚀 Características Actuales (Hito 1)

* **Componentes Dinámicos:** Tarjetas de productos (`CardPizza`) construidas dinámicamente mediante el paso de `props` (nombre, precio, ingredientes, imagen).
* **Renderizado Condicional:** Barra de navegación (`Navbar`) que alterna sus botones (Login/Register vs. Profile/Logout) simulando un estado de sesión.
* **Diseño Responsivo:** Implementación del sistema de grillas de Bootstrap para adaptar el catálogo a diferentes pantallas.
* **Sticky Footer:** Uso de utilidades de Flexbox (`min-vh-100`, `flex-grow-1`) para fijar el pie de página al fondo de la pantalla independientemente del contenido.

## 🛠️ Tecnologías Utilizadas

* [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* [React-Bootstrap](https://react-bootstrap.github.io/) / Bootstrap 5
* CSS3 (Flexbox & Grid)
